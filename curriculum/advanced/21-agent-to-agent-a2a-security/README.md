# 21 — Agent-to-Agent / A2A Security

Secure peer discovery, Agent Cards, task delegation, artifacts, lifecycle, and
notifications. Attack spoofed peers/cards, excessive delegation, artifact
poisoning, task replay, and webhook SSRF. Require authenticated transport,
server verification, per-request authorization, artifact validation, replay
protection, and resource limits. Use the [A2A specification](https://a2aproject.github.io/A2A/latest/specification/) as emerging protocol practice.
