# 20 — Cascading Failures and Blast-Radius Control

Model a compromised agent → bad tool call → poisoned state/memory → malicious
handoff → secondary agent → side effect attack graph. Compare it before and
after segmented credentials, separate memories, bounded tools, gateways,
approval, budgets, and a kill switch. Evaluate reachable resources, agents, and
side effects—not only first-attack blocking.
