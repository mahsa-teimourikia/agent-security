# 35 — Agent Security Architecture Review Workshop

Review flawed designs for prompt-based authorization, broad tools, shared
credentials, cross-tenant cache, untrusted MCP, unscoped memory, missing
approval/idempotency/kill switch/telemetry, and over-broad delegation. Produce a
formal report: finding, evidence, impact, control, owner, priority, test, and
residual risk. Score finding quality and remediation verification.
